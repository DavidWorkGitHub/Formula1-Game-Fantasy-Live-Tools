# F1 25 Fantasy Live — Sprint Weekend Fix

Run:

```cmd
npm start
```

Open:

```text
http://localhost:3000
```

This build separates the full weekend scoring into:

- Q = Race Qualifying
- SQ = Sprint Qualifying / Sprint Shootout
- SPR = Sprint Race
- Race = Grand Prix Race
- TOT = Q + SQ + SPR + Race

Manual scoring modes now include Auto, Q, SQ, Sprint, and Race.
